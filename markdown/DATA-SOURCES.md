# แหล่งข้อมูลการแข่งขันที่ตรวจแล้ว

ตรวจวันที่ 13 กันยายน 2569 โดยทดสอบ HTTP GET จากเครื่องพัฒนา ไม่ได้เปิด Cron หรือนำข้อมูลขึ้น Production

## ผลตรวจ

| แหล่ง | ช่องทาง | ผลทดสอบ | วิธีใช้ที่เสนอ |
|---|---|---|---|
| YSC / สวทช. | https://www.nstda.or.th/ysc/feed/ | HTTP 200, RSS XML, 10 รายการ | ทดลอง Cron อ่านข่าว แล้วตรวจหน้าประกาศเฉพาะรายการเพิ่มเติม |
| NECTEC | https://www.nectec.or.th/feed/ | HTTP 200, RSS XML, 10 รายการ | ทดลอง Cron โดยกรองข่าวรับสมัครการแข่งขันออกจากข่าวองค์กร |
| Contest Thailand | https://contest-thailand.com/feed/ | HTTP 200, RSS XML, 18 รายการ | ใช้ค้นพบประกาศหลายหมวด แล้วตามไปยืนยันกับผู้จัดต้นทาง |
| NIA | https://www.nia.or.th/event/InnovaTok-Contest-2026 | HTTP 200, HTML มีเนื้อหาไทย | เริ่มจากวางลิงก์แล้วสร้างร่าง ต้องพัฒนาตัวอ่านเฉพาะเว็บและตรวจหน้ารวมก่อนเปิด Cron |
| CEA | https://www.cea.or.th/th/news-updates/prompt-place-design-competition | HTTP 200, HTML มีเนื้อหาไทย | เริ่มจากวางลิงก์แล้วสร้างร่าง ยังไม่ได้ยืนยัน RSS/API |
| Contestwar | https://contestwar.com/robots.txt | fetch ไม่สำเร็จจากเครื่องนี้ | ยังไม่เลือกเป็นแหล่งอัตโนมัติ ไม่สรุปว่าเว็บใช้งานไม่ได้สำหรับทุกคน |

จำนวนรายการเป็นจำนวนที่ feed คืนในการตรวจครั้งนี้ ไม่ใช่จำนวนการแข่งขันที่เปิดรับสมัคร

## การเข้าถึงและการใช้เนื้อหา

- https://www.nstda.or.th/robots.txt อนุญาตเส้นทางทั่วไป ยกเว้น `/procurement-archive/`
- https://www.nectec.or.th/robots.txt ไม่ให้ crawl `/wp-admin/` ยกเว้น admin-ajax; feed ไม่อยู่ในเส้นทางที่ห้าม
- https://www.nia.or.th/robots.txt และ https://contest-thailand.com/robots.txt มี `Disallow:` ว่างในกลุ่ม `User-agent: *`
- https://www.cea.or.th/robots.txt คืน 404 ในการตรวจครั้งนี้
- การอ่านได้และ robots.txt ไม่ห้าม ไม่ใช่ใบอนุญาตให้นำบทความหรือภาพทั้งหมดไปเผยแพร่ซ้ำ ยังไม่ได้ยืนยันเงื่อนไขอนุญาตใช้ซ้ำของแต่ละแหล่ง
- เก็บข้อมูลข้อเท็จจริงที่จำเป็น เขียนสรุปเอง เชื่อมลิงก์ต้นทาง และตรวจสิทธิ์ก่อนนำภาพหรือข้อความยาวมาใช้ โดยเฉพาะแหล่งรวมข่าวของผู้อื่น
- ยังไม่พบ API กลางที่ยืนยันแล้วว่าส่งข้อมูลการแข่งขันครบทุกฟิลด์สำหรับแหล่งเหล่านี้

## ปัญหาข้อมูลที่พบจริง

หน้า https://www.nstda.or.th/ysc/ysc2026/ มีชื่อหน้าเกี่ยวกับครั้งที่ 28 แต่เนื้อหากล่าวถึง YSC 2027 ครั้งที่ 29 ระบุสร้างรหัสข้อเสนอถึง 25 สิงหาคม 2569 และส่งไฟล์ถึง 10 กันยายน 2569 จึงผ่านกำหนดทั้งสองวัน ณ วันตรวจ แม้เนื้อหายังเขียนว่าเปิดรับสมัคร

RSS ของ YSC มีข่าวผลการแข่งขันและเกียรติบัตรด้วย จึงใช้ RSS เป็นรายการข่าวให้พิจารณา ไม่แปลงทุก item เป็นการแข่งขันโดยตรง การแก้หน้าเก่าอาจไม่ปรากฏเป็น item ใหม่ ต้องตรวจหน้าที่ติดตามซ้ำด้วย

## ขอบเขตระบบดึงข้อมูลรอบแรกที่เสนอ

1. อ่าน RSS ทั้งสามแห่งวันละครั้ง จำกัดคำขอและมี timeout
2. จัดประเภทข่าวรับสมัคร ผลการแข่งขัน ข่าวองค์กร และรายการที่ยังไม่แน่ใจ
3. ตรวจซ้ำด้วย URL ปกติและข้อมูลชื่อเวที/ผู้จัด/รอบปี ไม่ใช้ชื่ออย่างเดียว
4. เก็บร่างพร้อมแหล่งที่มาและเวลาที่ดึง ค่าไม่ทราบ เช่น เงินรางวัลหรือวันปิดรับ ให้เว้นว่าง ไม่เดาเป็นศูนย์
5. ผู้ตรวจเปิดต้นทาง ตรวจวัน คุณสมบัติ และรายละเอียด แล้วแก้ไขหรือกดเผยแพร่
6. หน้าเก่าที่เปลี่ยนให้แสดงความต่างก่อนอนุมัติ ไม่เขียนทับข้อความที่ทีมงานแก้เอง
7. ให้แอดมินกดดึงตอนนี้ วางลิงก์ หรือเขียนรายการเองได้ งานอัตโนมัติและงานกดเองต้องกันการรันซ้ำ

เริ่มทดลอง RSS ของ YSC และ NECTEC เป็นแหล่งทางการ พร้อมใช้ Contest Thailand เป็นตัวค้นพบประกาศ ก่อนขยายตัวอ่าน HTML ของ NIA และ CEA
