# ภาษาไทย / อังกฤษ

อัปเดต: 30 กันยายน 2569

เว็บมีสองภาษา **ค่าตั้งต้นคืออังกฤษ** ผู้ใช้สลับด้วยปุ่ม **EN / TH** บนหัวเว็บ (บนมือถืออยู่ในเมนูสามขีด)
เว็บจำตัวเลือกไว้ในเบราว์เซอร์ (`localStorage` คีย์ `cw-lang`) และตั้ง `<html lang>` ให้ตรง

## กติกา

1. **ทุกข้อความที่ผู้ใช้เห็นมาจาก `src/i18n/` เท่านั้น** ห้ามพิมพ์ภาษาไทยหรืออังกฤษฝังในหน้าเว็บ
2. `src/i18n/en.ts` คือต้นฉบับ `th.ts` ผูกชนิดไว้กับมัน **ภาษาไทยขาดคีย์ไหน build ไม่ผ่าน**
3. `npm run check:i18n` ตรวจว่าไม่มีภาษาไทยหลงอยู่ในโค้ดหน้าเว็บ ไฟล์ที่ยังไม่ย้ายอยู่ในรายการ `PENDING` ของสคริปต์ (ตอนนี้ว่าง) ถ้าเพิ่มหน้าใหม่ต้องใช้พจนานุกรมตั้งแต่แรก
   - ป้ายของรหัสในไฟล์ข้อมูล (หมวด ระดับ ภูมิภาค ประเภท รางวัล ความถนัด) อยู่ใน `t.taxonomy` ไฟล์ข้อมูลเก็บเฉพาะรหัสและตรรกะ
   - ไฟล์ที่มีภาษาไทยได้คือ `CONTENT` ในสคริปต์: ข้อมูลตัวอย่าง (`sample-*.ts` ใช้เติมฐานข้อมูลตอน seed) ค่าที่ฐานข้อมูลเก็บเป็นข้อความไทย (`stored-values.ts`) และคลังคำจับหมวด (`focus-keywords.ts`) ห้ามเอาป้ายที่ผู้ใช้เห็นไปไว้ในไฟล์เหล่านี้
   - ฟังก์ชันจัดรูปแบบวันที่และตัวเลขอยู่ใน `src/i18n/format.ts` รับ `lang` เสมอ
4. **หน้าจัดการ (`/admin`) เป็นภาษาไทยอย่างเดียว** — ทีมใช้กันเอง ผู้ใช้ตัดสินเมื่อ 30 ก.ย. 2569 ไม่ต้องย้ายไป `src/i18n`
5. **เนื้อหาที่ผู้ใช้เขียนเองไม่แปล** — รายละเอียดเวที ประวัติเมนเทอร์ ข้อความแชต แสดงตามภาษาที่เขียนมา
6. คำขอ API ส่ง header `x-lang` ไปด้วย เพื่อให้เซิร์ฟเวอร์ตอบ error เป็นภาษาเดียวกับหน้าเว็บ (ฝั่งเซิร์ฟเวอร์ยังไม่ได้ทำ)
7. ตัวอักษรไทย: ไม่ใส่ letter-spacing, line-height เนื้อความ ≥ 1.6 — ใช้ `:lang(th)` ใน CSS

## รูปแบบภาษา

- อังกฤษ: **American English** (organizer, color) · **sentence case** ทั้งปุ่มและหัวข้อ ("Sign in", ไม่ใช่ "Sign In") · เขียนให้เป็นธรรมชาติ ไม่แปลคำต่อคำ
- ไทย: สุภาพแต่ไม่เป็นทางการเกิน · ใช้ "ครั้ง" กับจำนวนการปรึกษา · ตัวเลขเป็นเลขอารบิก

## การตรวจก่อน merge

- `npx tsc --noEmit` — จับคีย์ที่ขาดในภาษาไทย
- `npm run check:i18n` — จับภาษาไทยที่หลงในโค้ด
- `tests/i18n.spec.ts` — ค่าตั้งต้นอังกฤษ สลับเป็นไทยได้ และจำไว้หลังรีโหลด
- อ่านทวนทั้งสองภาษาทุกครั้งที่เพิ่มข้อความ ห้ามมีคำผิด
