## สิ่งที่ต้องตัดสินใจก่อนเผยแพร่

1. **ผู้ควบคุมข้อมูลคือใคร** ตอนนี้ยังไม่มีบริษัท ต้องระบุเป็นบุคคลธรรมดาผู้ดำเนินการเว็บ หรือรอจดบริษัทแล้วค่อยเผยแพร่
2. **ระยะเวลาเก็บข้อมูล** ร่างนี้เสนอตัวเลขไว้ (ดู data-inventory.md) ต้องยืนยัน และบางข้อระบบยังไม่ได้ลบให้อัตโนมัติ
3. **การส่งข้อมูลไปต่างประเทศ** ผู้ให้บริการทุกรายอยู่นอกประเทศไทย (สิงคโปร์/สหรัฐฯ) ต้องให้นักกฎหมายยืนยันว่าข้อความในนโยบายเพียงพอตามมาตรา 28–29
4. **ผู้ใช้อายุต่ำกว่า 20 ปี** กลุ่มเป้าหมายมีนักเรียนมัธยม ต้องตัดสินว่าจะขอความยินยอมจากผู้ปกครองอย่างไร (มาตรา 20)
5. **หน้า /privacy บนเว็บ** ยังไม่ได้สร้าง ทำได้หลังร่างผ่านการตรวจ และต้องลิงก์จากหน้าสมัครสมาชิก ฟอร์มสมัครเมนเทอร์ และท้ายเว็บ

## งานในระบบที่เอกสารนี้อ้างถึงแต่ยังไม่ได้ทำ

- ปุ่ม "ลบบัญชี" ให้ผู้ใช้ลบเองได้ (ตอนนี้ต้องแจ้งทีมงาน)
- ลบข้อมูลอัตโนมัติตามระยะเวลาที่กำหนด (เช่น email_log, รายการติดต่อที่ถูกยกเลิก)
- ส่งออกข้อมูลของตัวเอง (สิทธิขอรับสำเนา) ตอนนี้ทีมงานทำให้ด้วยมือ
